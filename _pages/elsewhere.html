--- layout: default title: Elsewhere permalink: /elsewhere/ description: >- Photographs from elsewhere — the places the box travelled to, and what was left of them. Numbered as plates, in no particular order. --- {%- comment -%} Two ways to fill this page, and the second is optional. 1. Put the file in assets/img/plates/ and commit. Every image in that folder is listed here, in filename order. Name it 01-, 02-, 03- and the order is the order they were taken. Nothing else to edit. 2. Add an entry to _data/plates.yml and it is used instead of the folder listing. That is how a photograph gets a caption, a place or a date. Only the entries listed there appear, in the order written. Both are plain files. There is no gallery to configure and no image processing: what is committed is what is published, so a photograph should be resized before it is committed (see the README). {%- endcomment -%} {%- assign listed = site.data.plates -%} {%- comment -%} The folder listing is filtered by hand rather than in one where_exp because Liquid's condition parser will not take parentheses, and the allowlist has to be an allowlist: a .DS_Store or a stray README dropped in the folder must not become a plate. Note it is `extname`, not `extension`, that a static file answers to, and that it carries the leading dot. {%- endcomment -%} {%- assign in_folder = site.static_files | where_exp: "f", "f.path contains 'assets/img/plates/'" -%} {%- assign filed = 0 -%} {%- for file in in_folder -%} {%- assign ext = file.extname | downcase | remove: "." -%} {%- if ext == 'jpg' or ext == 'jpeg' or ext == 'png' or ext == 'webp' -%} {%- assign filed = filed | plus: 1 -%} {%- endif -%} {%- endfor -%} {%- if listed and listed.size > 0 -%} {%- assign source = "listed" -%} {%- assign total = listed.size -%} {%- elsif filed > 0 -%} {%- assign source = "folder" -%} {%- assign total = filed -%} {%- else -%} {%- assign source = "empty" -%} {%- assign total = 0 -%} {%- endif -%}
